# AutoBuddy v0.5.9

> 修复代理检测报错、任务进度刷新丢失、启动失败按钮锁死三个真实缺陷。

## 变更

### 1. 代理检测报错修复
- **根因**：WebUI 代理层（18090）缺少 `POST /api/gh-register/proxy/test` 转发路由，请求被兜底通配路由转发到官方后端并返回 HTML 页面，前端 `r.json()` 解析 HTML 抛出 `SyntaxError`。
- **修复**：补全转发路由；前端增加 `content-type` 校验，非 JSON 响应给出明确中文提示。

### 2. 任务进度刷新即丢修复
- **根因**：`job_id` 只存在前端页面变量里，刷新后丢失；服务端任务实际仍在运行，但前端无重新挂载机制。
- **修复**：新增 `GET /api/gh-register/jobs` 列表接口；页面加载时主动查询运行中任务并自动恢复进度轮询。

### 3. 启动失败按钮锁死修复
- 任务启动失败时明确恢复按钮状态并展示失败原因，不再停留在「正在提交注册任务」。

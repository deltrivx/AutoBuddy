> 401 卡片视觉精修：提示块对齐正常卡片官方区高度（112px 实测）、顶部外框官方 badge 隐藏、按钮区/模型区灰化禁用。

## 修复

### 提示块尺寸对齐正常卡片（哥哥实测反馈）

上一版内框「需要重新登录」替换块尺寸过大。真机测量根因：`.wb-pool-relogin-desc` 残留横幅时代的 `flex: 1 1 240px`（删横幅时漏清），flex-grow 把两行说明文字拉到 240px 高、整块 290px。

修法（两处，只动 CSS）：

- desc 移除 flex-grow
- 替换块 `min-height: 112px`——112px 是**实测值**：正常卡片内框官方区三块高度之和（积分总览 30px + 近期到期行 17px + 积分明细 65px），非估算

### 顶部外框 badge 隐藏

官方 React 在 401 时会在 header 渲染「需重新登录」警示 badge（图标 + 文字）。按文本精确定位隐藏（visibility:hidden，不动布局）；右侧「更多账号操作」按钮和官方状态 chip 不受影响。提示只出现在内框。

### 按钮区/模型区灰化

需重登卡片的账号池控制条与模型标签区加 `.wb-relogin-disabled`（opacity 0.45 + grayscale(1) + pointer-events none + user-select none），参照旅行图标的灰色处理；恢复登录后自动还原。正常账号卡片零变化（真机对照验证）。

## 关于「顶部少一颗按钮」

真机逐卡测量：全部 28 张卡片 header 都只有 1 颗「更多账号操作」按钮；正常卡比 401 卡多出的是**官方状态 chip**（22px 图标，旅行/积分类），由官方 React 在 401 状态下自行不渲染，非本网关删除。重新登录后官方自行恢复。

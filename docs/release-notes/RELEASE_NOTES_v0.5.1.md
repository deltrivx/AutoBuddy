# AutoBuddy v0.5.1

> 内置 SQLite 数据库持久化、WebUI 用户安全认证、环境变量精简与代理精确分流。

## 新增与改进

### 1. 内置 SQLite 数据库与用户认证
- 容器内置 SQLite 数据库（挂载路径 `/data/.autobuddy/autobuddy.db`），保障数据在容器更新或重启后持久化。
- Web 控制台增加登录拦截与安全验证（默认账号 `admin`，初始密码 `admin123`），防止内网未授权操作。
- 侧边栏底部显示当前登录用户状态，并提供退出登录入口。

### 2. 精简环境变量与 WebUI 配置持久化
- 移除 Unraid 模板与 Compose 中冗余的临时注册参数环境变量。
- 所有注册配置（邮箱 API 基础地址、域名列表、认证 Header、密码等）在 WebUI「账号接入」页面直接保存并写入内置数据库。

### 3. 完整代理环境与精确分流规则
- 支持标准 `HTTP_PROXY`、`HTTPS_PROXY` 与 `ALL_PROXY`。
- `NO_PROXY` 预置精确 IP 列表（`localhost,127.0.0.1,::1,192.168.31.2,192.168.31.1...`），规避 Python httpx 对 CIDR 网段不兼容导致的 502/404 故障，确保模型请求走代理、内部容器通信走直连。

### 4. 侧边栏左上角品牌文字彻底修复
- 响应层精准替换上游前端 JS 中的 `WorkBuddy Switch` 文本为 **AutoBuddy**，配合 DOM 自动校准，彻底修复左上角旧版文字遗留。

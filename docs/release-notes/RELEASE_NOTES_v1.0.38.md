## 变更

### 「账号」行右侧控件间距归一

官方容器是 `gap-1`（4px），但中间的分隔线（`div.bg-border`）自带 `mx-2`
（8+1+8），使「自动执行」与「视图切换」之间出现 **25px 大间隙**。归一化把
分隔线水平 margin 归零 —— 分隔线本体保留，全行统一为容器的 4px；PC 4 控件、
移动端 5 控件（含搜索图标）间距一致。

### 刷新按钮补同款背景

官方刷新按钮（`lucide-refresh-cw`）是透明 ghost 形态，与旁边三个 `bg-accent`
按钮不一致。新增 `wb-acc-btn-flat` 类按官方 `--accent` 变量补背景，两个主题
自动跟随。

### 实现约束

React 重渲染会冲掉内联样式与追加的 class，归一化在每轮 run() 重放（幂等），
原始值记在 `dataset.wbOrigMl/Mr`，撤销时按记录还原。

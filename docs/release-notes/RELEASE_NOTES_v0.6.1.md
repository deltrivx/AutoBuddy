# AutoBuddy v0.6.1

> 修复积分统计页「今日消耗」恒为 0、右上角进度胶囊闪烁、代理检测顶掉下方布局，并把零余额账号移出巡检。

## 变更

### 1. 积分统计页「今日消耗」恒为 0
- **根因在官方底层**：`officialUsage.summary.usageToday` 与各账号 `usageToday` 长期回 `0.0`（`currentRemaining` 为 `null`），但 `status` 是 `complete`，前端据此认为官方口径可用，用 0 覆盖了顶层准确的 `summary.usageToday`（实测 1975.17）。
- **修复**：新增 `_reconcile_official_usage()`，顶层值 > 0 时以它为准；顶层也为 0 时才回退用 `daily` 里今天的数据重算；各账号 `currentRemaining` 用顶层同账号值补齐。

### 2. 右上角进度胶囊反复闪烁
- 旧实现每 2 秒轮询都会新建节点并重置淡出定时器。
- 改为全局单例：节点只建一次，内容无变化时完全不碰 DOM，淡出定时器全局唯一（8 秒）。

### 3. 代理检测顶掉下方布局
- 输入框右侧内嵌状态圆点（灰=未测 / 蓝=检测中 / 绿=可用 / 红=不可用）。
- 按钮文字轮换「检测代理 → 检测中… → 重新检测」。
- 结果只进圆点悬停提示与 toast，不再撑高卡片；改动输入自动回到未测态。

### 4. 零余额账号不再发起调用
- 新增 `_account_unusable_reason()`：余额 ≤ 0 的账号连凭据探测都不发。
- 字段缺失或无法解析时保守不跳过，避免误判。

### 5. 新账号卡片恢复全部功能按钮
- 新账号昵称常为空，前端仅按昵称建索引导致标题对不上、丢掉 `accountId`，交互按钮全数不渲染。
- 后端补 `name` 兜底与 `aliases`，并下发账号池中未被流水覆盖的账号；前端改为三重索引 + 位置兜底。

### 6. 其他
- 旧品牌名清理边界注释：`workbuddy-switch` 属官方 npm 包名/可执行文件名，保留不动；展示名仍由响应层替换。

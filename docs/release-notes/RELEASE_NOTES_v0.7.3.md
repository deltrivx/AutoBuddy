# AutoBuddy v0.7.3

> 恢复自动签到历史记录、修复新账号卡片设为首选无效、增强每日任务动作明细持久化记录（200 轮）、统一每日任务账号显示。

## 1. 自动签到历史记录恢复
- 位置迁移后，原设置页的 30 天自动签到历史记录在每日任务界面完整恢复，支持实时查看签到流水与结果状态；
- `patch_binary.py` 取消对设置页 `settings-auto-checkin` 的剔除，保留设置页原生签到配置与日志面板，两端历史数据（`/api/checkin/logs`）完全互通。

## 2. 修复新账号卡片「设为首选」无效
- **根因**：新账号添加后初始不在账号池白名单中。点击设为首选时，前端提交的白名单未包含该账号，导致后端安全校验发现首选账号未入池而退回自动模式；
- **修复**：设为首选时自动将该账号加入白名单，与老账号交互逻辑完全对齐。

## 3. 每日任务动作追踪与持久化（保留 200 轮）
- 细化任务动作解析：记录每个账号具体执行的任务（签到、领奖、抽奖、任务项等）；
- SQLite 数据库表 `wb_daily_accounts` 增加 `actions` 字段，并在明细面板中完整直观展开。

## 4. 统一每日任务与签到账号显示
- 关联主账号池，显示真实的账号昵称与标识，消除裸手机号造成的两组账号割裂感。

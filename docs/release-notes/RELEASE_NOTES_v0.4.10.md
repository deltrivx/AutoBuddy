## 修复：「检测账号」的结论更好读

账号卡片上的「检测账号」现在会一并说明**结论是怎么得出来的**，而不再把上游的原始响应码
透出来。

| | 修改前 | 修改后 |
| :--- | :--- | :--- |
| 提示内容 | 凭据有效 | 凭据有效（上游已接受该凭据） |
| 响应里的原始状态码 | 会带出来 | 不再给出 |

检测用的是「发一个不存在的模型名，看上游怎么回」这个办法：上游若以「模型不存在」拒绝，
恰恰说明它已经认下了这个凭据。因此这个请求**本来就会**得到非 200 的响应 ——
把原始状态码原样显示出来，会与旁边的「凭据有效」互相矛盾，让人以为检测没成功。

改后只回报结论与判定依据，三种结论如下：

| 结论 | 含义 | 建议 |
| :--- | :--- | :--- |
| 凭据有效 | 上游已接受该凭据 | 无需处理 |
| 凭据已失效 | 上游以鉴权类错误拒绝 | 重新登录该账号 |
| 暂时没有结论 | 上游未给出可判定的响应 | 稍后再试 |

「检测账号」只报告结论，不会改动任何配置。

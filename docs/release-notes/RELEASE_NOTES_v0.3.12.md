> v0.3.11 上线后做了一次全量验收（容器 / 二进制 / DOM / 接口 / 日志 / 数据 六个维度）。
> **主体全部达标**，但全量扫描又揪出两个漏网项 —— 它们都藏在「被删掉的逻辑原本会遮住」的位置。

## 1. 账号页「CodeBuddy CLI 接入」引导横幅（真实残留）

它的结构是「满足条件才显示」的一个横幅，而**条件取决于官方后端返回的状态**。
v0.3.11 只删掉了横幅里的按钮，横幅本身没进移除清单。

关键点在于：当前后端恰好让条件为假，所以**它没显示** ——
但只要后端改口（未接入 / 需升级 / 待同步），横幅就会带着
「接入 CLI / 更新 CLI 认证 / 升级 CLI helper」按钮重新冒出来。

这正是「彻底移除，不是隐藏」没有做到的最后一处。**本版把它从产物里物理删掉。**

顺带说明：账号页右上角那组桌面状态图标及其悬停提示已被 v0.3.11 整块覆盖，属死代码，无需再动。

## 2. Token 统计里两个已失效的数据来源分类

Token 统计原本返回 4 个数据来源分类，其中两个对应已移除的桌面 CLI / IDE ——
容器里不存在对应的会话日志，是纯死重。现在只保留两条真实存在的产品线。

**安全性已核对**：界面取用逻辑对未知分类会自动回落到主产品线，
即使浏览器本地缓存里残留旧分类名，也不会白屏。

## 3. 验收结论（未改动项，仅供留档）

- 补丁**这次真的生效了**：容器内产物与官方原始文件确实不同，且产物体积保持一致。
- 设置页只剩「外观」与「自动签到」；账号池注入正常，说明此前做的账号池、归因、Token 契约等优化**一项没丢**。
- 首页副标题由响应层等长替换，且带长度断言，不等长会直接报错，不会静默失败。
- 遗留（未处理，待决定）：数据卷里 CLI 时代留下的持久化残留（约 18 MB），删掉即可回收。

## 不改变的行为

账号管理、自动签到、账号池调度与 Token 统计全部保持不变。

## 🎯 本次解决的两个问题

### 1. 国际版账号后面的 CodeBuddy IDE / CodeBuddy CLI 按钮，这次是**真的没了**

之前两个版本尝试过两种「遮掩」方案，都不成立：

| 版本 | 方案 | 结果 |
| :--- | :--- | :--- |
| v0.3.2 | 用观察器按标签名加隐藏样式 | 按钮依然存在 |
| v0.3.3 | 用样式选择器直接命中 | 按钮依然存在 |

原因是这两个按钮和徽章由界面框架在**异步数据到达后**才渲染，遮掩的时机永远赌不赢。

**本版改为在产物层物理移除**：

- 那三个槽位其实是同一个容器里的三个孩子，整个容器被原地抹掉，从此不会生成这个节点。
- 其他页面复用的「当前账号」徽章组件，返回值被清空（保留声明结构，避免破坏语法）。
- 前端代理里所有与之相关的遮掩代码**一并删除**，不再双份维护。

### 2. 账号池：请求级并行调用

- 一条对话请求仍由**单个账号**完成（避免上下文与计费错乱），
  但**多个并发请求会分摊到不同账号**，不再全部挤在同一个账号上。
- 候选账号先按「参与调用」白名单过滤，再剔除 Token 缺失或已过期的账号。

### 3. 启用开关 + 手动首选

- 每个账号卡片新增「参与调用 / 点击停用」与「设为首选」两个按钮。
- 白名单为空时语义为「全部启用」；保存为明确列表后即成为白名单。
- 手动模式固定使用首选账号；单次请求也可用请求头或请求体临时指定账号。

### 4. 新增账号池接口

网关提供状态查询与配置更新接口，控制台提供对应的转发接口。

## 打包机制升级

补丁引擎从「硬编码超长匹配串」升级为「锚点 + 语法配平扫描」，
扫描器能正确跳过字符串与模板字面量，因此界面代码里的括号不再干扰表达式边界判定。

## 不改变的行为

账号管理、自动签到与 Token 统计保持不变。
本版是账号池并行调度能力的首个版本。

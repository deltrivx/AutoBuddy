## 智能路由页暗色主题对齐（方案 A）

路由页是从 Magpie 1:1 移植的独立视觉体系，其主题块硬编码了浅色令牌（`--card:#fff`，暗色覆盖 `--card:#181b21`）。套在暗色 app 上表现为**实色近黑面板**，与官方设置/账号/总览等页的**半透明浮层**观感完全不同——这是“样式肉眼可见都不对”的根因。

本次将 `html.dark #wb-routing-view` 的全部令牌改写为官方 shadcn 暗色值：

- `--card: oklab(0.279 -0.00709772 -0.040381 / 0.3)`（半透明浮层，与官方账号页卡片完全一致）
- `--line / --line-2 / --border: oklch(100% 0 0 / 0.1)`（白 10% 描边）
- `--fg / --fg-2: oklch(92.9% .013 255.508)`（近白文字）
- `--accent: oklch(69.6% .17 162.48)`（官方绿强调色）
- `--pill / --card-2` 等派生令牌同步改为半透明派生

卡片、实时轨迹舞台、节点、账号列表行全部变为与官方页一致的半透明浮层 + 白 10% 描边。

### 细节对齐

- 卡片标题 `.wb-rt-card-title` 13px → 14px（与官方 `h2` 一致）
- 路由轨迹 / 列表 / 统计小卡片圆角 10px → 12px，过渡更柔

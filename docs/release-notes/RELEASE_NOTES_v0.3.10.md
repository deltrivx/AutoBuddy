> v0.3.9 让 CodeBuddy CLI 在容器里跑起来了；本版把「跑起来」补成「跑得顺」。
>
> ⚠️ 本版能力已在 v0.3.11 随 CLI 一并移除，此处仅作历史留档。

## 1. git 身份默认值

容器内没有 git 身份配置。CLI 的版本控制能力（查看 diff、提交变更、创建分支）
依赖用户名与邮箱，缺失时提交会直接报错。

现在镜像内置 **系统级**默认身份，让你在容器里一条命令就能覆盖：

```bash
git config --global user.name "你的名字"
```

用系统级而非全局，正是为了让覆盖不需要改镜像。

## 2. 工作目录挂载位

Unraid 模板新增**可选**挂载位，作为容器内可操作的项目文件目录。
不挂载也能跑 CLI，只是没有可操作的项目文件。

## 3. 环境自检确认（无需改动）

- CLI **自带 ripgrep**，无需另装。
- 自动更新已关闭并生效。
- Node / npm / git 版本均满足要求。

## 不改变的行为

账号管理、自动签到、账号池调度与 Token 统计全部保持不变。

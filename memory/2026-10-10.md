# 2026-10-10 AutoBuddy

## v0.9.41：今日消耗 0 点未重置（跨天串账）+ 7日/本月滚动求和

### 用户报告

01:03 反馈「今日消耗 6,371.68，明显有问题」，并提出三点：今日应在北京时间 0 点自动重置并叠加到近7日/本月；需确认 7日/本月如何自动刷新；确认后清 bak 容器。

### 实测根因（不是"没重置"，是"串账"）

关键判据：当时才过 **1.29 小时**，却显示昨日全天量级。

后端 daily 桶由**稀疏快照**做差值得出，实测全部 15 个账号：

| 账号 | 基准快照 | 最新快照 | 间隔 | 剩余差 |
|---|---|---|---|---|
| 全部 15 个 | **10-09 20:07** | 10-10 00:57 | **4.85h** | 合计 6371.68 |

⇒ 今日桶基准锚在昨晚 20:07，把 10-09 晚间约 3.5 小时（含 22:24 那轮每日任务）整段算进 10-10。
交叉验证：当天仅 **395** 次请求，往常 3135 次请求才对应 5280.01 —— 差约 10 倍。

**快照节奏约 5 小时一次**，远粗于日界精度要求，跨天必然串账。后端是闭源引擎，采集改不了。

### 修复

① **今日桶重归因**：用网关自己的高分辨率账本（`token_stats.db`，逐请求带时间戳）按**午夜前后请求数**拆开这段消耗，把昨天的部分归还给昨天。有请求按请求数拆、无数据退化为时间占比；**守恒**（只搬运不改总量）。未跨午夜 / delta ≤ 0（配额补充）/ 无基准快照 → 跳过；异常吞掉返回 0，绝不拖垮积分页。

② **7日/本月改为按 daily 桶滚动求和**：实测后端本就是这么算（25941.74 = 末7日求和、27807.18 = 10月求和，精确匹配）。显式重算后 daily 桶每天前进一格即自动刷新，不会像 `officialUsage` 那样停更 16 天。

|---|---|---|
| 今日 | 6371.68 | **1299.09** |
| 昨日 10-09 | 5280.01 | **10321.79** |
| 近7日 / 本月 | 25941.74 / 27807.18 | 25910.93 / 27776.37 |

总量守恒（差值 0.26% = 这半小时新增消耗）；单调校验两项 True。

### ⚠️ 踩坑两则（都是测试桩的坑，非生产缺陷）

1. 自建 `FakeTime` 缺 `struct_time` → 被测代码抛 `AttributeError`，而该函数为优雅退化**吞掉异常返回 0**，症状是「端到端全返回 0」，极易误判成生产代码失效。
2. `FakeTime.strftime` 忽略传入的 `struct_time`，一律用固定时刻 → `ymd == tmd`，「加回昨日」分支永不命中，症状是守恒断言失败。

教训：**被测函数为了健壮性吞异常时，测试必须先剥掉 except 看真异常**，否则会把桩的 bug 当成产品 bug 排查。

### 另一处真实失误（已修）

重建容器时把 `AUTH_PASSWORD` 写成字面量 `***`（3 字符，旧值是 9 字符），会导致 WebUI 登录失效。已用 `docker inspect` 从备份容器取回真值重建修正（密码只在服务端变量流转，未打印）。

## 2026-10-12 补充：未按模板重构的错误 + 闪屏/漂移修复

### 用户批评：「未按照模板重构」（我的错误）

v0.9.42 初版把顶层 accounts **对象直接 alias** 给 `ou.accounts[]`，违反仓库既定的
「1:1 复刻官方页面」模板规范。两套 schema 不同：

  官方 ou.accounts: models / requestCount / reportedTotal / fetchedCount /
                    ok / error / detailTruncated，daily 行含 models
  顶层 accounts:    checkedInToday / currentRemaining / variant / lastCheckinAt …

直接 alias 会让按官方模板渲染的账号明细与逐模型分解**全部缺料**。
改为按官方模板重建 13 字段；逐模型明细（credit/requestCount）由新增
`_gateway_models_by_account()` 从 token_stats.db 按「账号+日期」聚合。

### 测试桩踩坑（同一根因第三次）

抽取函数执行时必须一并注入**模块级缓存常量**（_MDL_CACHE 等）。缺了会 NameError，
而被测函数为优雅退化**吞掉异常** → 症状是「未接管却静默通过」。
教训：被测函数吞异常时，测试必须先剥掉 except 看真异常，否则把桩 bug 当产品 bug。

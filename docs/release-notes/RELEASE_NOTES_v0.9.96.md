## 三、修掉「logo 和主题左右散开」

你反馈的「部分页面偶尔出现左右两个 logo 和主题散开而不是和页面对齐」。

**根因**：`wbSyncTopbarAlign()` 用 `main > div` 选内容容器做对齐基准，但 `main` 下同时挂着官方容器和两个注入视图 —— 命中的可能是**上一个页面**的残留节点（已 `display:none`，量到 0×0，或尺寸完全不同）。实测 logo 块在 `x=146`（总览/每日）与 `x=139`（其余四页）之间交替漂移，主题控件同理会左右散开。

**修法**：按视图状态精确取容器 —— 概览取 `.wb-ov-wrap`、每日任务取 `.wb-daily-wrap`、官方页从 main 的**可见**子节点里找；取不到就退出，不猜、不套旧值。

## 四、另外两项

### 每日任务页执行记录明细移到行内

原来点「执行记录」的任何一行，明细都渲染到**页面底部**。现在点在哪个行下方，就展开在那一行正下方，再点一次收纳。明细区固定 260px 高度内部滚动 —— 实测 66 行账号表格靠它滚动，不撑大卡片。

### 每日任务页部分内容左右未对齐

任务清单 / 任务记录 / 执行记录三张卡片加一个 row，是 `#wb-daily-view` 的**直接子元素**，不在 `.wb-daily-wrap` 里 —— 实测 `x=0 w=1409` 占满视口，而同层正确内容是 `x=147 w=1116`。

新增 `wbNormalizeDailyLayout()` 幂等归一化，并处理 `.wb-api-row` 自带 `margin: 0 20px` 造成的 20px 额外内缩。

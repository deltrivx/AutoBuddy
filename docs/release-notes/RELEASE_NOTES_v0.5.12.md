# AutoBuddy v0.5.12

> 注册进度可视化、日志降噪、登录遮罩修复与失败诊断能力补强。

## 变更

### 1. 右上角实时进度指示器
- 常驻右上角胶囊，显示当前阶段与百分比，切换页面仍可见。
- 任务结束后自动淡出，不长期占位。

### 2. 进度百分比按阶段推进
- 由固定 0%/100% 两档改为阶段加权递增，杜绝长时间停在 0%。

### 3. 容器日志降噪
- 过滤高频只读轮询接口的 2xx 访问日志，保留写操作与全部 4xx/5xx。

### 4. 登录遮罩修复
- 底色 0.78 → 0.92，模糊 6px → 18px，并补充 Safari 前缀。

### 5. 提交后页面诊断快照
- 记录 URL、标题、人机验证元素、错误文本并保存截图，定位注册卡点。

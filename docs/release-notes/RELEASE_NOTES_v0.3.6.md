## 🔍 上一版漏了什么

v0.3.4 的发布说明写「账号卡片三个产品槽位已物理移除」，但实际上官方界面里这组槽位**存在两份**：

| 位置 | 形态 | v0.3.4 状态 |
| :--- | :--- | :--- |
| 卡片**底部** | 带文字标签的三个槽位 | ✅ 已移除 |
| 卡片**头部账号名右侧** | 紧凑图标行 | ❌ **漏掉了** |

实际界面上「国际版账号后面一个 CodeBuddy IDE 和 CodeBuddy CLI 按钮」，指的正是**头部图标行**。
v0.3.4 之后它依然在，所以问题看起来「没修好」。

## 为什么上一版没验出来

v0.3.4 的验证用的是**固定字面量断言**：

- 检查的是「某段固定文本在产物里出现几次」；
- 而这些标签实际由表达式**动态拼接**（例如「正在切换…」与「设为…」是同一条模板的两个分支）；
- 固定字面量在原始文件里出现次数**本来就是 0** —— 断言等于没验。

本次改为**用真实浏览器加载页面后检查 DOM**，并断言「带『当前账号』字样的元素数量为 0」。

## 🎯 本次修复

头部图标行内含三个槽位，各自都有「已接入显示徽章 / 未接入显示按钮」两个分支，共六个表达式：

- 「设为 WorkBuddy 当前账号」按钮 与「WorkBuddy 当前账号」徽章
- 「切换到 CodeBuddy IDE」按钮 与「CodeBuddy IDE 当前账号」徽章
- 「设为 CodeBuddy CLI 当前账号」按钮 与「CodeBuddy CLI 当前账号」徽章

整行一次性**物理移除**，父节点渲染正常。

## 保留项

「管理账号」下拉里的「刷新 Token / 手动签到 / 删除账号」在容器内可用，未做改动。

## 不改变的行为

账号管理、自动签到、账号池调度与 Token 统计全部保持不变。

# AutoBuddy v0.5.11

> GitHub 注册改走纯邮箱路径，邮箱参数可在界面配置，中止接口补充容错。

## 变更

### 1. 注册路径改为纯邮箱注册
- 移除 Google OAuth 环节，直接打开 `github.com/signup` 填表注册。
- 设备验证码由后端自动收信提取（`wait_for_device_code`），无需人工介入。
- 失败提示区分「未进入注册页」与「表单提交后未完成」，定位更准。

### 2. 邮箱参数 UI 可配
- 新增「邮箱名前缀」（可留空，留空为纯随机）。
- 新增「邮箱名随机长度」（4–32）。
- 两项均可在「账号接入」页面直接调整并持久化，无需改代码或重建镜像。

### 3. 中止接口容错
- 中止任务请求补充响应类型校验，接口返回非 JSON 或失败时给出明确提示。

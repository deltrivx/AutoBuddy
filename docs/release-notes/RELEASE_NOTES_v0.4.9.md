## 一、新增：按账号停用

账号卡片上多了一个停用开关，一键让某个账号退出自动轮询，再点一次恢复。

| | 效果 |
| :--- | :--- |
| 停用后 | 自动轮询与「首选账号」不再选中它 |
| 显式指定该账号的请求 | 仍然可用 |
| 卡片上的标注 | 手动停用与巡检停用分别标明来源 |

停用针对的是「轮询时不要选它」，而不是「禁止调用」。需要临时用被停用的账号兜底时，
直接指定该账号即可，不必先去界面解除停用。

停用状态保存在独立文件里，与账号池的启用列表互不覆盖：关掉模型巡检不会让停用失效，
恢复巡检也不会把你手动停用的账号偷偷放回来。

## 二、新增：检测账号

账号卡片上多了「检测账号」按钮，点一下发一次轻量鉴权请求，就地回报这个账号现在能不能用。
只报告结论、不改动任何配置，不消耗额度。

| 结论 | 含义 |
| :--- | :--- |
| 凭据有效 | 账号可以正常调用 |
| 凭据已失效 | 需要重新登录该账号 |
| 暂时没拿到结论 | 网络或上游异常，可稍后再试 |

## 三、新增：巡检增加凭据预检

模型可用性巡检在探测模型之前，会先确认这个账号的凭据是否有效。

| | 效果 |
| :--- | :--- |
| 凭据有效 | 照常逐个探测模型 |
| 凭据已失效 | 不再探测它名下的模型，也不写入模型禁用 |
| 探测不到结论 | 照常往下探测，不据此下判断 |

一个凭据失效的账号，它名下所有模型都会失败。先花一次请求确认凭据，既省掉后面几十次注定
失败的探测，也避免把「凭据过期」记成「这些模型全都坏了」。

凭据确认失效时可以自动停用该账号（可在设置里关闭）。网络抖动、上游 5xx 这类拿不到结论的
情况不会停用账号。这项预检本身也可以在设置里关闭。

## 四、修复：窄屏下设置页被挤成一条竖线

手机上打开设置页，侧边栏固定占 220px，在 430px 宽的屏幕上吃掉近一半，正文被压到只剩两百多像素，
文字被压成竖排。

| | 修复前 | 修复后 |
| :--- | :--- | :--- |
| 窄屏下的侧边栏 | 固定展开，占 220px | 自动收起，正文占满 |
| 宽屏下的侧边栏 | 可手动收起 | 不变 |

自动收起只在窄屏生效，不会覆盖你在宽屏下的手动设置。

## 五、修复：窄屏下设置项的文字与按钮互相挤压

设置页里成对的「说明文字 + 右侧按钮」是横排的，窄屏时右侧不肯让位，把左边的说明压成一条竖线。
现在窄屏下改为上下堆叠，各自占满整行。「关于」面板里的键值对同样改为上下排列。

## 不改变的行为

模型可用性巡检的开关与判定规则（限流跳过、凭据失效整账号跳过、整轮无有效信号作废）、
模型级禁用的来源保护、账号池调度（并行轮询 / 手动首选 / 请求级指定账号）、模型别名路由 ——
**全部保持不变**。

账号池的启用列表与「首选账号」语义不变。已有的账号数据、禁用配置、用量统计不受影响，
升级不需要做任何迁移。

对外提供的 OpenAI 兼容接口、请求与响应字段**没有任何增删**。

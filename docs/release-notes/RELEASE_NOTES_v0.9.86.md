## 一、主界面重新设计（左右分离 + 背景磨砂）

### 参考设计

按用户提供的参考图落地：左侧窄边栏（磨砂半透明 + 高亮选中态）+ 右侧主内容区（卡片列表）。

### 实现要点

| 项 | 做法 |
| :--- | :--- |
| **侧边栏磨砂** | `backdrop-filter: blur(18px) saturate(140%)` + `color-mix` 半透明底色，内容区可透出底色形成层次 |
| **卡片分离感** | 统一 16px 圆角、1px 细边框、双层柔和阴影，与侧边栏明确分离 |
| **配色** | 强调色沿用官方 `--primary`，**不引入第二套配色**，深浅主题自动适配 |
| **主内容宽度** | 宽屏限宽 1180px 居中，窄屏吃满 |

### 移动端竖屏适配（重点）

官方侧边栏是 220px 固定纵栏，在 430px 屏上会吃掉一半宽度，正文被挤成一条竖线。
改为**贴底横向导航条**：

- 侧边栏 `position: fixed` 贴底，横向排列、可滚动（隐藏滚动条）
- 图标在上、文字在下，`min-width: 56px`，文字超宽省略
- 品牌区与折叠按钮隐藏（底部条没地方放）
- 主题 dock 横排在导航右侧，三个按钮固定 30×32
- 主内容区底部留 76px，最后一项不会被挡
- 极窄屏（≤380px）文字再缩一档，5 个入口放得下

### 两个踩过的坑（已修）

**坑 1：折叠态规则把底部条压成 68px**

```
aside.wb-collapsed { width: 68px !important }   ← 特异性 (0,1,1)
@media 720px { aside { width: 100% !important } } ← 特异性 (0,0,1)
```

特异性更低 → 68px 赢 → 实测竖屏侧边栏只剩 68px、nav 被压到 9px、5 个导航项挤成一团。

修法：补一条同等特异性的 `aside.wb-collapsed` 覆盖规则。

**坑 2：主题 dock 竖排被挤成 15px 高**

竖排是桌面端侧边栏的形态（高度充裕）；底部条只有约 62px 高，竖排会把三个按钮各压到 ~15px，**实测点不中**。改横排后每个按钮 30×32，可点。

## 二、联网搜索引擎：前端可自选配置

### 用户诉求

> 「搜索引擎作为可选项，前端添加 UI 配置，用户自行配置搜索引擎，也可以用其他的，
> 而不是把我的 key 写死到仓库里，因为这是开源的，别人也可以用的，
> 所以每个人可以在前端 UI 可以选择常见搜索引擎输入 API 配置自己的搜索引擎」

### 实现

新增 `SEARCH_PROVIDERS` 注册表，内置 6 种常见引擎：

| 引擎 | 特点 | 需要密钥 |
| :--- | :--- | :--- |
| **Tavily** | 专为 AI 设计，返回摘要+结果，默认选项 | ✅ |
| **Serper** | Google 真实搜索结果，含知识图谱 | ✅ |
| **Bing Web Search** | 微软必应，Azure 门户申请 | ✅ |
| **Google CSE** | Google 官方自定义搜索，需 Key + `cx` | ✅ |
| **博查搜索** | 国内可直连，中文结果好 | ✅ |
| **SearXNG** | 自托管元搜索，聚合多来源 | ❌ |

**密钥不进仓库**（开源项目硬约束）：

- 每个引擎的 `api_key` 只落在用户自己的 `assistant_config.json`
- secret 语义与 LLM provider 完全一致：
  `GET 不回明文` / `不提交=保留` / `空串=清除` / `有值=覆盖`
- 提供「清除已保存的密钥」按钮（显式提交空串）
- `_test_search_providers.py` 里有一条**仓库密钥扫描**断言，
  扫出真实密钥形态（`tvly-<20+>` / `sk-<40+>`）就让测试失败

**架构**：每个引擎一个适配函数，请求/响应差异在适配层归一化成
统一的 `(answer, [{title, url, content}])`，工具层不关心差异。
以后加引擎只需往注册表加一条 + 写一个适配函数。

**连通性测试**：新增 `POST /api/assistant/search-test`，填完密钥立刻验证，
**不落盘**（测试不该有副作用）。

**向后兼容**：环境变量 `TAVILY_API_KEY` 仍被识别，仅用于兼容老部署；
新用户全程只需在设置页操作，不用碰环境变量。

## 三、设置页调整

| 改动 | 说明 |
| :--- | :--- |
| **账号资料置顶** | 原顺序 外观→API→巡检→助手→通知→账号→关于，账号资料排倒数第二，每次要滚过半页。现在排第一 |
| **主题挪到侧边栏左下角** | 新增三段式控件（系统 / 浅色 / 深色），与官方 `appearance-theme` 读写**同一份 localStorage**，实测 React 不会回弹；设置页里那个官方主题项随之隐藏，两处不会各说各话 |

### 单元测试

48 个测试文件全部通过，0 失败。其中新增 `_test_search_providers.py` 81 项断言：

- 注册表完整性与适配器一一对应
- **仓库内无真实密钥形态**（开源硬约束）
- secret 语义四态（保留 / 清除 / 覆盖 / 不回明文）
- 引擎切换后 `_search_credential()` 跟着变
- 工具启用条件（未启用 / 启用无密钥 / 启用有密钥 / 免密钥引擎）
- 老配置（缺 `searchProviders` 字段）向后兼容

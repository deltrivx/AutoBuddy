## 变更

### 1. 401 异常卡片登录提醒区域视觉对齐

- **背景与问题**：此前为避免异常卡片提醒块过大，将其高度压缩为 53px。但在并排对比时，正常卡片上方包含完整的积分展示区（总积分、积分包数、更新时间、到期进度条等，高度约 140px），导致异常卡片的上部区域出现明显的塌陷和缩减，与左侧正常卡片大小不一致。
- **优化方案**：
  - 让异常提示块（`.wb-official-relogin`）直接占满原积分包展示区域，设置 `min-height: 140px` 与垂直居中布局，消除空间塌陷。
  - 通过前端脚本在同页正常卡片中就地量取积分区域高度并进行动态像素级对齐，实现两张卡片上下排版严格对称。
  - 内部异常信息居中排布，边框与底色保持统一视觉规范，整体整洁美观。

### 2. 账号管理页面卡片三原则精细化排序

优化卡片排序算法，形成清晰的三层优先级：

1. **第一原则（状态分层）**：
   - 正常卡片（在账号池中且无异常）排在最前（rank 0）；
   - 非白名单卡片（未入账号池但状态正常）居中靠后（rank 1）；
   - 异常卡片（401凭据失效、被停用、上游拦截）垫底排在最后（rank 2）。
2. **第二原则（分类内按积分降序）**：
   - 在上述三种分类内部，再按照账号积分多少降序排序，积分多的靠前，积分少的靠后。
3. **第三原则（无积分兜底）**：
   - 没有积分数据的卡片不参与额外积分排序，稳定排在有积分账号之后，保持稳定的字母序兜底。

### 3. 仓库残留文件全面清理

清理此前误提交与过期的非项目核心文件，保持标准开源仓库的整洁规范：
- 移除误提交的 Agent 系统模板及持久化记忆（`AGENTS.md`、`IDENTITY.md`、`SOUL.md`、`USER.md`、`memory/`）。
- 移除 `patch/` 目录废弃的历史原型脚本（`proxy_server.py`、`web_proxy.py`）。
- 移除 `gateway/vendor/` 遗留的历史备份文件（`workbuddy_daily.py.bak-*`）。

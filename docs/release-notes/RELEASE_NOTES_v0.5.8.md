# AutoBuddy v0.5.8

> 账号接入页面优化 + GitHub 注册流程全自动化。

## 变更

### 1. 界面与配置修正
- 浏览器环境文案更正为 `Patchright Headless Chromium · 免检测`。
- 删除与「注册专用出网代理」重复的 Clash REST API 地址输入框及自动切换节点复选框。

### 2. 新增代理检测
- 代理输入框旁新增「检测代理」按钮，实测代理对 GitHub 的可达性，返回状态与延迟。

### 3. GitHub 注册全自动化
- 新增从验证邮件正文提取 8 位设备验证码（Launch Code）的能力。
- 注册流程调整为「先创建临时邮箱 → 再注册 → 自动收信取码 → 自动回填」。
- 前端设备验证码输入框移除，启动任务不再需要人工填码。

### 4. 风控对抗配置补全
- `打码最大重试轮数`：验证码失败后可自动换题重试。
- `表单填充节流基数`：拉长表单提交前的停顿，降低风控评分。

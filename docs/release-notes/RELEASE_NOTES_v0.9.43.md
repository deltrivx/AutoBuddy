> 修复左侧 5 个标签依次切换时的闪屏与页面漂移。

## 用户报告

> 从上到下依次点击左侧 5 个切换标签，会触发闪屏和页面漂移。

## 实测定位（CDP 真实浏览器，非推测）

用 CDP 连真实 Chromium，鼠标逐个点击 5 个标签（账号管理 / 词元统计 / 积分统计 /
每日任务 / 系统设置），每步记录 DOM mutation 数、CLS、scrollX/scrollY、body 高度：

| 标签 | mutation 数 | CLS | 漂移 | 主内容可见子节点 |
|---|---|---|---|---|
| 账号管理 | 126 | 0.0000 | 0 | 1 |
| 词元统计 | 36 | 0.0000 | 0 | 1 |
| 积分统计 | **226** | 0.0000 | 0 | 1 |
| 每日任务 | 103 | 0.0000 | 0 | 1 |
| 系统设置 | 20 | 0.0000 | 0 | 1 |

两个结论：

1. **闪屏** = 切换瞬间上百次 DOM mutation —— 每次切回「每日任务」都无条件
   重拉全部接口并整块重渲染（`wbLoadWbDailyData()` 每次都跑），页面闪一下。
2. **漂移** = 各视图高度不同导致纵向滚动条出现/消失，内容区可用宽度随之突变
   （CLS 测不到，因为它不是元素位移而是容器宽度变化）。

## 修复

1. **切换不再无条件重渲染**：给每日任务数据加 30s TTL，
   首次加载或数据过期才重拉，切回来时直接复用已有 DOM。
2. **消除滚动条抖动**：`html { scrollbar-gutter: stable; }` 为滚动条预留固定槽位，
   内容区宽度不再随滚动条有无而突变。

## 验证

- Python 语法通过；内嵌 JS 经 `node --check` 通过（抽取 `<script>` 块校验）。
- 全量 25 个测试文件全绿，无回归。

# AutoBuddy v0.9.9

> 新增每日任务积分统计（今日 / 签到 / 任务 / 总积分）与浮窗「今日积分」。

## 1. 每日任务页新增「积分统计」栏

参考积分统计页的卡片样式，在每日任务页顶部新增一栏，展示四项数据：

| 数据项 | 口径 |
| :--- | :--- |
| **今日积分** | 今日签到积分 + 今日任务积分 |
| **签到积分** | 今日签到类任务获得的积分 |
| **任务积分** | 今日除签到外其他任务获得的积分 |
| **总积分** | 按**已有历史记录累加**得出，此后每天在已有记录上继续累加 |

卡片下方附带最近 5 天的明细表（日期 / 签到 / 任务 / 合计），
便于核对「总积分」是怎么累加出来的。

## 2. 右下角浮窗新增「今日积分」行

在「今日消耗」下方新增一行「**今日积分**」，
与每日任务页的「今日积分」同源，显示今天通过签到与任务获得的积分。

浮窗现有四行：

```
总积分      11265.37
```

## 3. 新增后端接口

`/api/wb-daily/credit-summary` —— 按天聚合每日任务获得的积分。
纯本地 SQLite 读取，不走上游请求。`web_proxy` 侧同步增加转发路由。

## 实现说明

### 积分从哪来

积分从 `wb_daily_tasks` 的 `detail` 日志文本中解析，规则为：

```
\+\s*(\d+(?:\.\d+)?)\s*积分
```

一行出现多次则累加（例如 `+300积分+8能量` 取 300）。

**为什么不直接用 `total_credits` 字段**：
实测 250 条历史记录中，该字段**全为 NULL** —— 上游并未写入。

### 口径如何划分

- `checkin` → **签到积分**
- 其余任务（领奖 / 抽奖 / 盲盒 / Buddy / 旅行 / 批量接受）→ **任务积分**

> 注：实测 18 条 `checkin` 记录中目前**不含积分增量**
> （上游签到日志里没有 `+N积分`），所以「签到积分」当前多为 0。
> 一旦上游在签到日志中输出积分增量，该项会自动开始统计。

### 实测历史数据

```

  2026-09-27   2350
  2026-09-26   3900
  2026-09-25    600
```

均来自领奖（`claim`）任务。

## 升级说明

重建容器即可，`/data` 数据不受影响。

- 无新增或删除环境变量；
- 无数据库结构变更（复用既有 `wb_daily_tasks` 表）；
- 历史记录中的积分是**按已有数据算出来的**，往后每天在已有记录上继续累加。

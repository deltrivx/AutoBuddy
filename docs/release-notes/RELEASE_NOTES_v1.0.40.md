## 变更

标准 = 「签到/旅行」开关按钮的未选中态：背景透明、无边框、36px、圆角 12px、
图标 16px / 描边 2 / 前景色；选中态只是多了 `bg-accent` + `text-brand`（官方
开关行为，不碰）。

| 控件 | 改动 |
| :--- | :--- |
| 分隔线 | 整个隐藏 —— 只归零 margin 仍剩 1px 线 + 8px，与相邻 4px 不等宽；隐藏后全行统一 4px |
| 搜索框 | 透明背景、无边框；hover / 聚焦显 `var(--accent)`；透明对两主题天然一致 |
| 列表切换 | 官方常驻 `bg-accent`，运行时挂 `wb-acc-btn-ghost` 剥掉 |
| 刷新 | v1.0.38 补的背景撤回，同样挂 ghost 类 |
| 移动端图标 | 克隆 class 时剥离 `bg-accent`，不因克隆选中态按钮而常亮 |
| 图标 | 搜索图标 14px → 16px 对齐官方 size-4，描边统一 2 |

归一化每轮 run() 重放（幂等），分隔线原始 display 记在
`dataset.wbOrigDisplay`，撤销时还原。ghost 类只剥背景，官方 hover 反馈保留。

# AutoBuddy v0.6.4

> 修复官方新加的账号（如「一杯美式」）不出现在账号池控件里。

## 问题

账号文件有**两份**，内容并不一致：

| 文件 | 账号数 | 说明 |
|---|---|---|
| `/data/.wb-switch/accounts.json` | 8 | 官方维护的那份，用户新加的账号先出现在这里（含「一杯美式」） |
| `$AB_DATA_DIR/accounts.json` | 6 | 容器自己的副本，字段更全 |

而 `_load_accounts_for_models()` 早先的实现是「**找到第一个存在的文件就 break**」——永远只认其中一份。

结果：官方新加的账号（「一杯美式」等）进不了 `/api/account-models` 与 `/api/account-pool`，其卡片上「参与调用 · 点击停用 / 设为首选 / 检测账号 / 已调用 N 次」四个控件**全数不出现**。

## 修复

改为**合并两份文件**：

- 按账号 ID 去重，字段互补
- 后遍历的本地副本覆盖官方那份（本地字段更全，含 `variant` 等）
- 无 ID 的条目回退用昵称/邮箱做键，不整条丢弃
- 读不到文件时返回空列表，绝不因账号文件异常而让调用方失败

## 排查备忘

判断「账号池缺账号」时的两步确认：

1. `cat /data/.wb-switch/accounts.json` 与 `$AB_DATA_DIR/accounts.json` **分别**看账号数——两者不一致就是这个问题
2. 请求 `/api/account-pool` 与 `/api/account-models`，确认新账号的 `id` 真的出现在返回里

只对比其中一个文件，或只看接口返回，都会漏掉「两份文件不一致」这个根因。

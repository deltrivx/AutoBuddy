## 变更

### 账号页搜索框落位调整（用户 2026-10-25 方案）

| 端 | 位置 |
| :--- | :--- |
| PC（≥640px） | 搜索框插进「账号」行右侧图标按钮容器**首位**：「账号」标题之后、自动签到/自动执行等图标之前，与图标的间距 = 容器自身 gap（与两个图标间距一致）；框高 36px 与图标对齐 |
| 移动端（<640px） | 内联框隐藏，改显**同款风格的搜索图标按钮**（克隆旁边官方图标按钮的 class，外观完全一致）；点击弹出搜索弹窗，16px 输入框（防 iOS 聚焦自动放大）+ 计数徽章 + 关闭按钮，输入即过滤 |

要点：

- 锚点定位走「H2 文本 === 账号」判据找「账号」行，不依赖易变 class 名；
  找不到时**兜底退回 v1.0.35 的独立过滤行**（PC 右对齐、移动端吸顶），
  官方改版时功能不断供。
- 过滤状态在 PC 内联框与移动端弹窗之间双向同步（同一 state.q）；过滤生效中
  移动端图标点亮（`wb-acc-search-icon-on`），提醒「当前列表处于过滤态」。
- 弹窗支持 ✕ 按钮 / 点击遮罩 / Esc 三路关闭；Esc 挂在弹窗自身 keydown 上，
  不碰 document 监听。

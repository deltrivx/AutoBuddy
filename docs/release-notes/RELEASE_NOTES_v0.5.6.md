# AutoBuddy v0.5.6

> 登录安全增强（滑动验证、去预填）与 Clash REST API 地址修正。

## 变更

### 1. 登录安全增强
- 默认密码统一为 `password`，模板与后端逻辑一致。
- 账号与密码输入框不再预填默认值，也不显示任何默认凭据提示。
- 新增拖拽滑动验证（内联 SVG，无外部依赖）：未拖动到最右侧无法提交登录，失败后自动复位。

### 2. 配置项修正
- 「Clash REST API 地址」前端默认值与回填统一为 `http://192.168.31.10:9090`。
- 「注册专用出网代理」默认 `http://192.168.31.10:7890`。

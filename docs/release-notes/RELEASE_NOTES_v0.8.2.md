# AutoBuddy v0.8.2

> 账号并发分摊（在飞最少优先）、头像全面圆形化、用户球默认纯圆 + 悬浮展开、密码按位数掩码。

## 1. 账号并发分摊

此前选账号是「固定顺序单指针轮询」：串行请求下看着没问题，但并发场景里同一个账号可能在别的请求还没返回时被反复命中。当候选集里只有少数账号支持某个模型时，慢请求会把那个账号拖成瓶颈——这正是「响应速度慢」的一个放大器。

v0.8.2 改为**在飞请求数最少优先**：

- 每个账号的「在飞请求数」实时维护，选账号时优先挑当前最闲的；
- 同分时仍按轮询起点遍历，长期分布保持均匀；
- 上游请求结束（成功 / 失败 / 客户端断开）都会释放计数；
- 状态接口新增 `inflight` 字段，可直接观察并发分布。

一条对话请求仍由单个账号完成，**不会**把同一个请求拆成两份——分摊的是并发请求，不是上下文。

## 2. 头像全面圆形化

- 官方方形 App 图标改由后端 SVG 出口提供：**浅蓝纯圆底衬 + 居中官方 logo**，四周留白均匀，彻底解决硬裁切导致的边缘不规则与直角违和；
- 官方 / 预设 / 自定义三类头像统一正圆，选择器内一律 42px，选中态蓝色描边；
- 官方图标缺失时兜底返回纯圆底衬，绝不破图。

## 3. 右下角用户球

- **默认形态是 44px 纯圆头像**：无文字、无内边距错位，视觉干净；
- **点击或鼠标悬浮都会展开**成胶囊并显示昵称与浮窗；
- **点击页面其他位置、或鼠标移开后自动收纳**（带 220ms 宽限，方便鼠标移向浮窗）；
- 窄屏（≤720px）自动缩为 40px。

## 4. 设置页密码展示

- 移除「会话有效期 N 小时，到期后需重新登录」提示；
- 已设定密码时按**实际位数**用等宽 `*` 掩码展示（悬浮提示总位数），不泄露任何真实字符；
- 环境变量锁定的密码仍保持「不可修改」提示。

## 5. 升级说明

- 无数据迁移、无接口破坏性变更；
- 新增 `inflight` 状态字段与 `/api/auth/status` 的 `passwordLength` 字段，均为增量；
- 头像出口 `/api/auth/avatar` 在非自定义时改为返回 `image/svg+xml`。

# AutoBuddy v0.8.0

> 右下角用户球替换侧边栏用户条，新增账号资料管理（昵称 / 头像 / 用户名 / 密码），会话有效期收紧为 24 小时。

## 1. 右下角用户球

此前的用户标识是塞在侧边栏底部的一条「绿点 + 用户名 + 退出」。移动端窄屏收拢侧边栏时，用户名没有跟随隐藏规则，把「退出」按钮挤成一小坨，既难看也难点中。

v0.8.0 把它彻底挪出侧边栏：

- **右下角固定悬浮球**：圆形头像（默认官方图标）+ 昵称；窄屏（≤720px）自动缩成纯头像圆，不再占地方；
- **点击弹出账号卡**：头像 + 昵称 + 用户名（不同时才显示）+ 在线状态、登录时间、会话到期倒计时；
- **操作入口**：修改资料（昵称 / 头像）、修改用户名、修改密码、退出登录；
- 点击浮层外部自动收起，z-index 低于登录遮罩，不阻挡任何页面操作。

## 2. 账号资料管理

设置页新增「账号资料」卡片，与右下角浮层共用同一组接口：

- **昵称**：默认与用户名相同；修改用户名时，若昵称从未自定义过则自动跟随新用户名，一旦自定义过就独立存在；
- **头像**：默认官方图标，可上传自定义图片（PNG / JPG / WebP，≤200KB），落盘 `/data/.autobuddy/avatars/`，可随时切回官方图标；
- **用户名**：修改需验证当前密码，成功后所有会话作废、强制重新登录；
- **密码**：修改需验证当前密码，成功后同样强制重新登录（此前该接口一直存在但没有前端入口）。

### 环境变量锁定态

容器环境变量显式设置 `AUTH_USERNAME` / `AUTH_PASSWORD`（或其别名）时：

- 对应的修改入口**灰置**，悬浮提示「环境变量已通过环境变量设置」；
- 原因：每次容器启动都会用环境变量覆盖数据库里的凭据，界面改了也会被冲掉，直接禁用避免误导；
- 昵称与头像**不受限**，可自由修改。

## 3. 会话有效期 7 天 → 24 小时

- Cookie `max_age` 与服务端 `sessions.expires_at` 同步收紧为 24 小时；
- 可用环境变量 `AUTOBUDDY_SESSION_HOURS` 调节（正整数小时，默认 24）；
- **启动时自动把历史超长会话压回当前有效期上限**——旧版本签发的 7 天票据在升级后立即到期，保证「过了有效期必须重新登录」的口径对存量会话同样生效。

## 4. 侧边栏收拢态补完

导航收拢为纯图标时，名称挪到 `data-wb-label` 属性，悬停时用 CSS 气泡提示——收拢态零文字残留，鼠标悬停即可辨认入口。

## 5. 升级说明

- 无数据迁移：昵称 / 头像走 `system_config` 键值表，头像文件落数据卷；
- 升级后所有已登录会话立即按 24 小时上限重新计算，部分用户需要重新登录一次；
- 模板新增可选变量 `AUTOBUDDY_SESSION_HOURS`（默认 24，不需要改可以不填）。

# AutoBuddy v0.9.14

> 修正 v0.9.13 中被内联样式与选择器特异性抵消的三处对齐。

## 背景

v0.9.13 部署后做实测验证时发现：**三处改动写了，但页面上并未生效**。
逐一排查后确认，三处的根因相同 —— **内联样式 / 选择器特异性**压过了 CSS 规则。

## 三处修正

### 1. 表格 `padding` 未生效

积分统计明细表的 `th` / `td` 用的是**内联样式**：

```html
<th style="text-align:left;padding:3px 6px;font-weight:500">日期</th>
```

内联样式优先级高于 CSS 类选择器，所以 v0.9.13 里改
`.wb-daily-wrap th { padding: 6px 10px }` **完全无效**。

现将内联值直接改为 `6px 10px`，与官方一致。

### 2. 主按钮被误降级

v0.9.13 加了两条规则：

```css
.wb-daily-wrap .wb-api-btn          { font-size: 14px; min-height: 32px; }  /* 特异性 0,2,0 */
.wb-daily-wrap .wb-api-row .wb-api-btn { font-size: 12px; min-height: 28px; }  /* 特异性 0,3,0 */
```

第二条特异性更高，导致**行内所有按钮**都被压到 12px / 28px ——
包括「刷新」「保存配置」「立即执行」这些应当与官方主按钮一致（14px / 32px）的按钮。

现已移除该条行内降级规则。

### 3.「全部立即签到」按钮偏小

该按钮带内联 `style="font-size:11px"`，会压过 CSS 规则，
比同页其它按钮小一档。已移除内联字号。

## 教训

这三处的共同点是：**改了 CSS，但被更高优先级的规则抵消**。
v0.9.13 只做了静态检查（AST / `node --check` / 单测），这些都能通过，
却无法发现「样式没真正生效」。

**只有部署后实测 computed style 才能发现这类问题。**
本版部署后已实测确认三处均生效。

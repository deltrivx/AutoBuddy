## 问题：卡片上有两个「调用次数」，口径不同却长得很像

| 位置 | 内容 | 实际口径 |
| :--- | :--- | :--- |
| 模型标签提示 | `网关调用 8 次 · 约 88 Token · 官方记录 8 次 · 积分 0` | **模型**被调用几次 |
| 模型区标题 | `可用模型 · 33（已调用 5）` | 该账号**用过几个模型** |
| 账号池条 | `已调用 0 次` | 该**账号**被分摊到几次请求 |

「已调用 5」与「已调用 0 次」用同一个词、含义完全不同 —— 这正是混淆源。

## 改法

- 模型标签提示**去掉**调用次数，只留用量类信息（`约 N Token` / `积分 N`）；
- 模型区标题**去掉** `（已调用 N）` / `（暂无调用记录）` 后缀，恒为 `可用模型 · 33`；
- **保留**模型标签的蓝色高亮 —— 颜色变化已足够表达「这个模型被调用过」；
- **保留**账号池条的 `已调用 N 次` —— 现在卡片上唯一的调用次数，不再有二义。

模型维度的调用次数仍在接口返回里（未删除，避免破坏外部消费方），只是界面不再渲染它。

## 改前 / 改后

```
改前：可用模型 · 33（已调用 5）
      hy3 → 网关调用 8 次 · 约 88 Token · 官方记录 8 次 · 积分 0

改后：可用模型 · 33
      hy3 → 约 88 Token · 积分 0
```

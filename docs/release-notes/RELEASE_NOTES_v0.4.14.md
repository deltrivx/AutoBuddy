上一版把提示改成了人话，方向对了，但**出错时的提示还是太长** —— 一句话能说清的事，
被写成了三句。

## 一、修复：异常账号的提示收成一句

出错时，提示会依次拼上三段内容，而它们说的是同一件事：

> 账号甲：账号被上游风控拦截，暂时用不了（账号被上游风控拦截）该账号被上游风控拦下，重新登录没用；请检查账号状态或联系上游

| 段落 | 内容 | 问题 |
| :--- | :--- | :--- |
| 结论 | 账号被上游风控拦截，暂时用不了 | 已经说完了 |
| 依据 | 账号被上游风控拦截 | 与结论同义 |
| 建议 | 该账号被上游风控拦下，重新登录没用；请检查账号状态或联系上游 | 第三遍，且前半句还是同义 |

一段话要读三遍才能确认「哦，就是不能用」。现在提示**只保留结论那一句**：

> 账号甲：账号被上游风控拦截，暂时用不了

判定依据与完整成因移到提示的悬浮说明与接口返回里 —— 需要排查时看得到，日常使用不必读。

## 二、修复：建议不再复述结论

- 凭据失效档去掉了「重新登录即可恢复」：结论已经是「登录已过期，请重新登录」，
  再说一遍只是让提示变长。
- 风控档保留「重新登录没用，需要确认账号状态」—— 这一句提供的是**结论里没有的信息**
  （重登解决不了），值得留着。原先跟在后面的「也可先停用该账号避免占用轮询」删掉了，
  因为巡检已经自动做了这件事，不必再让人手动操作。

## 三、修复：术语统一

自检面板与接口说明里的「账号受限」统一改成「账号被风控」，与提示口径一致。
同一个状态在界面不同位置有两个叫法，会让人以为是两回事。

## 四档提示的实际长度

| 情况 | 提示 |
| :--- | :--- |
| 正常 | 账号甲：账号正常，可以放心使用 |
| 风控 | 账号甲：账号被上游风控拦截，暂时用不了 重新登录没用，需要确认账号状态 |
| 过期 | 账号甲：登录已过期，请重新登录 |
| 未测出 | 账号甲：这次没测出结果，请稍后重试 稍后重试 |

正常账号仍然只有一句；出错时最多两句（结论 + 建议），不再出现同义重复。

## 不改变的行为

- 账号有效性的判定标准、巡检的停用与放回规则均不变，本轮只改提示的呈现。
- 提示的配色（绿 / 琥珀 / 红）、持续时间与位置照旧。
- 完整的判定依据与成因仍在接口返回里，排查时可见。

## 🔧 改进亮点

### 1. CodeBuddy IDE / CLI「当前账号」状态徽章彻底隐藏

- 这两个绿色对勾徽章检测的是**宿主机上的桌面客户端**，容器里根本不存在，
  因此状态恒为「未运行 / 未安装」。
- 从**样式选择器**直接命中隐藏，不再依赖脚本执行时机，即使后渲染也会被立即隐藏。
- 这两个徽章**只对当前激活的那一个账号**有意义（其他账号本来就不会显示），
  所以隐藏对其他账号无影响。

### 2. 请求明细按时间倒序展示

- 改为显式按时间**倒序**排列，不再依赖上游流水的拼接顺序。
- 浏览器侧不需要改动，表格组件已按入参顺序渲染。

### 3. 请求明细精简为最近 200 条

- 仅保留最近 200 条明细，避免接口返回体过大。
- 前端默认每页 50 条保持不变。

---

## 📦 升级方式

```bash
docker pull ghcr.io/deltrivx/workbuddy-switch:v0.3.3
docker pull ghcr.io/deltrivx/workbuddy-switch:latest
```

> Unraid 请通过容器模板重建，**不要手工拼接 `docker run`**。
> 数据目录不变（`/data`），升级不会动到账号数据。

## 不改变的行为

账号管理、自动签到与账号池调度保持不变。

> 概览页「近 30 天积分消耗」趋势图改为固定 31 天窗口，缺失日期补 0，图表尺寸与位置不变。

## 一、问题

数据总览的「近 30 天积分消耗」卡片，趋势图实际只有 **3 个点**。

**根因**：上游 `/api/credits/stats` 的 `daily` 字段只保留 3 天（实测 `['2026-10-15', '2026-10-16', '2026-10-17']`），前端直接取来就画，于是图永远只有近 3 天。

## 二、修法

改为**固定 31 天窗口**：今天往前推 30 天，逐日生成横轴，上游没有的日期补 0。

这与官方积分统计页的口径一致 —— 本文件 `_rebuild_official_usage()` 里 `_days` 的构造方式（`_start_d` = 今天 - 30 天，逐日递增到 `_today_d`），官方页面同样是「窗口固定 31 天、缺的补 0」。

按你的说法：数据没有的补 0，后面随时间推移自然就填满了。

## 三、实测

```
折线顶点数: 31        ← 之前 3
非零点数:   3         ← 上游只提供 3 天
末点圆:     true

图表尺寸:   724 × 130  ← 尺寸不变
viewBox:   0 0 600 130 ← 位置不变
```

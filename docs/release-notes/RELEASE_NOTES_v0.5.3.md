# AutoBuddy v0.5.3

> Token 与积分统计数据校准、Unraid 模板描述优化与强制安全认证。

## 变更

### 1. Token 统计与积分统计数据校准
- **国内版与国际版分别归集**：解决此前国内版与国际版 Tab 数据 100% 相同、账号混在一起的异常，两边分别按各自版本独立统计 Token 总量、模型消耗与账号归因。
- **清除积分统计僵尸账号**：自动剔除已删除或失效的残余账号，重新计算总剩余额度与近期用量，避免积分面板出现无效账号。

### 2. 移除认证开关 & 模板描述优化
- 取消 `AUTH_ENABLED` 切换开关，默认强制安全认证，保障 NAS 公网或内网访问安全。
- 优化 Unraid 模板中各端口、挂载路径与代理分流变量的中文描述。

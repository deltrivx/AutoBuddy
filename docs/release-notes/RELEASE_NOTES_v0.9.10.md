# AutoBuddy v0.9.10

> 积分统计栏对齐官方样式、浮窗数值按语义着色、退出登录文字左对齐。

## 1. 每日任务页「积分统计」栏改为对齐官方样式

### 问题

上一版是我**自造的样式**：18px 小方块、四项各自着色、左对齐 ——
与你要参考的官方积分统计页并不一致。

### 修正

按官方 `/credit-stats` 页的**实测 computed style** 重做：

| 元素 | 官方实测值 |
| :--- | :--- |
| 外框 | `rounded-2xl`（16px）+ 1px 边框 + `bg-card/70` |
| 单项容器 | `flex-col` + `items-center` + `justify-center` + `px-4 py-5` + `text-center` |
| 数字 | **26px** / `font-weight: 600` / **居中** |

数字格式也改为千分位 + 两位小数，与官方一致（如 `6,850.00`）。
四项之间用竖线分隔，窄屏自动换行。

> 说明：样式取自浏览器实测的 computed style，而非截图比对 ——
> 实测值比目测更精确，也避免了对图片内容的依赖。

## 2. 浮窗右侧数值按语义着色

让四个数字一眼可辨：

| 行 | 着色规则 |
| :--- | :--- |
| 总积分 | 主色（余额本身，中性） |
| 今日消耗 | `>0` 用橙（在消耗），为 0 用中性灰 |
| 今日积分 | `>0` 用绿（今天赚到了），为 0 用中性灰 |
| 账号池 | 全部启用用绿，存在未启用用橙（提示有账号闲置） |

实测当前数据下：今日消耗 9.94 显示橙色、今日积分 2350 显示绿色、
账号池 7/11 显示橙色。

## 3. 浮窗「退出登录」文字左对齐

菜单项原有 `padding: 8px 10px`，导致文字比上方统计行的标签
**向右缩进 10px**。现改为 `padding: 8px 0`。

视觉样式（红色文字 / 圆角 / 悬浮反馈）**保持不变**，仅修正左边缘对齐。

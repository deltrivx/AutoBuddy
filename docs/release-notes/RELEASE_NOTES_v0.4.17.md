这个版本加了一个「账号接入」面板：在容器里直接跑完 GitHub 账号注册，并把浏览器从镜像里挪了出来。

## 一、新增：GitHub 账号自动化接入

WebUI 新增「账号接入」面板，在**容器内一站式**跑完整个流程：

```
Google OAuth 登录 → 注册 GitHub → 绑定域名邮箱 → 收验证邮件 → 设主邮箱 → 删旧邮箱
```

几个关键取舍：

| 事项 | 做法 | 原因 |
| :--- | :--- | :--- |
| 浏览器 | 容器内直接 `launch`（headless） | **不外接 CDP**，不依赖宿主机桌面环境或 9222 端口 |
| 邮箱验证 | Cloudflare D1 收件箱 | catch-all 路由直接落库，无需自建邮件服务 |
| 节点轮换 | OpenClash REST | 原先写死 Windows 命名管道，换成 REST 后纯 Linux 容器可跑 |

面板会实时回显每一步进展，中途失败也会明确指出卡在哪一步。

## 二、变更：浏览器改为运行时下载

原先 Chromium 打在镜像里。问题是它解包后上百 MB，且跟着上游频繁发版 ——
每次重建镜像都要重背一份，推拉都变慢，而**多数时候根本用不到**。

现在改为：

- 镜像**只装 Playwright 驱动**与 headless 运行时系统库；
- 「账号接入」面板提供「下载浏览器」按钮，点了之后下载到挂载卷并持久化；
- 下载过程有实时日志，失败会显示原因并可重试；
- 未安装浏览器时直接开始注册，会明确提示先去下载，而不是跑到一半才报错。

**收益**：镜像明显瘦身，构建更快、推拉更轻；容器重建或升级**不必重下浏览器**；
一次下载可多容器复用。

## 三、变更：新增浏览器缓存挂载路径

容器新增挂载点：

```
/data/.wb-switch/browsers
```

Unraid 模板对应新增「浏览器缓存目录」配置项（默认
`/mnt/user/appdata/workbuddy-switch/browsers`）。这个目录持久化后，
浏览器只需下载一次。

## 升级提示

- **首次使用需点一次「下载浏览器」**：升级后镜像里不再带 Chromium，
  不点下载直接开始注册会被拦下并提示。
- 旧容器的挂载配置里没有浏览器目录，**用模板更新容器时请确认该路径已加上**，
  否则下载的浏览器会随容器删除而丢失。

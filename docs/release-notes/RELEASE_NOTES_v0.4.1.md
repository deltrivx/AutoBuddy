# v0.4.1 — 模型级禁用：点一下就拉黑「某账号的某个模型」

## 你提的问题

> 虽然账号提供了很多模型，但部分账号的模型随着优惠政策或者时效性可能无法调用。
> 现在每个账号下方都展示了可用模型、调用过就变色重点显示，这个设计很好。
> 但部分账号的个别模型可能不能调用，希望能把模型做成**可点击**的：
> 点一下就变成禁用模式、不参与轮询调用，再点一下恢复原来的颜色（正常显示或调用后的颜色）。

这个需求的分寸拿捏得很准 —— 它要求的不是「停用账号」，而是「**账号 × 模型**」的粒度。

---

## 为什么不能简单地停用账号

账号池解决的是「**哪个账号**参与调用」。但实际使用中还有更细的一层：

一个账号有几十个模型，受优惠政策调整、免费额度到期或上游限流影响，往往只有**个别模型**
在这个账号上调不通，而**其他模型仍然好用**。

- 停用整个账号 = 过度反应，把还能用的模型一起丢掉了；
- 放任不管 = 轮询会时不时撞上那个死模型，把请求打失败。

所以这一版把禁用粒度落在「**这个账号的这一个模型**」，与账号池配置**正交、互不覆盖**。

---

## 一、模型标签变成可点击

账号卡片下方的每个模型标签现在都可以点：

| 状态 | 外观 | 含义 |
| :--- | :--- | :--- |
| 默认 | 灰底常规字 | 可用，参与轮询 |
| 已用 | 蓝底加粗 | 该账号**真实调用过**这个模型（原有设计，完整保留） |
| **已禁用** | **灰底 + 删除线** | **点击后进入，不再参与该账号的轮询** |

几个细节是刻意这样做的：

- **禁用优先于已用**。三态互斥，禁用态压掉蓝色高亮 —— 否则你刚点掉的那个看起来「没反应」。
- **不做成按钮墙**。标签默认无边框、无下划线，只有悬停/键盘聚焦时才显形，暗示「可以点」，
  但整排看起来仍是标签而不是一排按钮。
- **灰掉而不是红掉**。红色读起来像故障告警，而这里是用户主动做的选择，不是出错。
- **`已禁用 N` 徽章**。卡片标题旁显示计数，账号卡片折叠时也能看出这里动过手。
- **支持键盘**：`Tab` 聚焦 + `Enter` / `Space` 触发。

## 二、网关侧真正做到「跳过」

点了标签只是 UI 状态，**关键在网关是否真的不再用它**。这一版在 `select_account()` 上做了改造：

1. **模型在选账号之前取出**。路由提前避开死组合，而不是把请求发给上游、等它报错再回头。
2. **禁用了该模型的账号从候选里剔除**，只影响本次请求，不动全局配置。
3. **别名归一**。禁用 `hy4` 会连同目标模型 `hy3` 一起挡住 ——
   否则调用方把 `hy4` 换成 `hy3` 就绕过了禁用。
4. **安全回退**。若某模型在**所有**账号上都被禁用，网关**不返回** 401/409，而是回退到不过滤，
   让上游返回真实错误。在网关层编一个「无账号可用」，会掩盖真实原因，反而更难排查。
5. **不传 `model` 时不过滤**，行为与升级前完全一致。

## 三、持久化

策略落在 `/data/.wb-switch/model_policy.json`，与 `account_pool_config.json` **完全分离**：

```json
{
  "a1b2c3d4": ["hy3", "kimi-k2.5"]
}
```

- **只记禁用项**。未列出的模型一律视为可用 —— 官方上新模型时天然是可用态，不需要迁移配置。
- `tmp` + `os.replace` 原子替换，不会留下半截 JSON。
- 文件缺失 / 损坏 / 结构不对，一律回退为**空策略**（全部可用），绝不抛异常影响正常调用。

## 新增接口

| 接口 | 说明 |
| :--- | :--- |
| `GET /account-models/config` | 读取禁用策略：`policy` / `disabledTotal` |
| `PUT /account-models/config` | 切换禁用：`{"accountId","model","disabled"}`，或 `{"accountId","models":[…]}` 整份覆盖 |
| `PUT /api/account-models` | Web 控制台用：转发禁用切换 |

同时 `/api/account-models` 每账号新增 `id` 与 `disabled` 字段供 UI 渲染；
`/account-pool/status` 新增 `modelPolicy`；`/gateway/info` 新增 `models.disabledCombos`。

## 验收

新增两个本地单测，均 stub 掉 fastapi / httpx，**无需安装依赖**：

- **`_test_model_policy.py`（13 项断言）**
  别名归一（禁用 `hy4` 命中 `hy3`）、读写回环、损坏文件回退、非 dict 回退、
  未知账号、原子写无 `.tmp` 残留、去重排序。

- **`_test_model_routing.py`（8 项断言）**
  无策略时轮询覆盖全账号、禁用后不再落到该账号、该账号其他模型不受影响、
  别名禁用同样挡住目标模型、全禁用时回退而非 `None`、不传 `model` 时不过滤、
  显式指定被禁用的组合返回 `None`。

另外做了容错兜底：某账号「一条调用记录都没有、但已被禁用过模型」时也会被补进结果，
否则它的禁用状态会静默丢失，用户会以为点了没生效。

账号管理、自动签到、账号池调度（round-robin / 手动首选 / 请求级指定账号）、

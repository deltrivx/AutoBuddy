# AutoBuddy v0.8.1

> 品牌口径统一、右下角浮窗改为实时积分信息、「无 Buddy」徽章轻量化、头像体系升级。

## 1. 品牌统一

登录认证页标题「AutoBuddy 控制台」改为「AutoBuddy」，与浏览器标签标题、侧边栏品牌口径一致。

## 2. 右下角用户球交互简化

- **平时只显示头像圆**，点击展开浮窗时才露出昵称——默认形态更轻，不占视觉焦点；
- 浮窗不再显示会话有效期倒计时：过期重新登录即可，倒计时只会制造焦虑；
- 浮窗改为展示三项**实时信息**：
  - 剩余积分（官方 credits/stats，代理层已过滤僵尸账号并校准汇总）；
  - 今日消耗（同上口径）；
  - 账号池可用数（网关信息实时统计）；
- 修改资料 / 修改用户名 / 修改密码入口统一收进设置页「账号资料」，浮窗只保留退出登录，排版更清爽。

## 3. 「无 Buddy」旅行徽章轻量化

账号卡片右上角的「无 Buddy」文字徽章改为**虚线描边小飞机图标**，悬浮时给出完整说明（去官方端完成一次对话并领养 Buddy 即可自动旅行）。账号领养 Buddy 后官方文案自动变化，徽章自然恢复官方原样，无需任何持久化处理。

## 4. 头像体系升级

- **官方图标圆形化修正**：官方 App 图标是方形，此前圆形硬裁会切坏内容；改为 contain 完整显示 + 底衬，视觉上是完整的圆形官方头像；
- **新增 6 款内置圆形图标**：月牙 / 星辰 / 新叶 / 暖阳 / 心动 / 宝石，全部为渐变底 + 简约符号的同风格内联 SVG，无外部资源依赖；
- 资料弹窗与设置页「账号资料」卡片共用一组九宫格选择器，选中态高亮，上传自定义头像后自动取消预设选中。

## 5. 升级说明

- 无数据迁移、无接口破坏性变更：新增头像预设值走原有 `profile.avatar` 配置键（`preset:<key>` 格式），旧值（official / custom）继续有效；
- 头像预设为内联 SVG，不发起额外网络请求。

# AutoBuddy v0.9.12

> 每日任务页整体对齐官方页面布局与样式、侧边栏收纳提示修复、浮窗四色区分。

## 背景

每日任务页是后来新增的页面，容器宽度、标题、卡片圆角等此前都是自定义写法，
与其它官方页面（账号管理 / 积分统计 / Token 统计）存在明显差异。
本版按**源码与浏览器实测双重对比**逐项对齐。

## 1. 布局与样式对齐

| 项目 | 官方页面实测值 | 每日任务页（改前） | 改后 |
| :--- | :--- | :--- | :--- |
| 容器宽度 | `max-width: 1180px` | `max-width: 960px` | `1180px` |
| 容器内边距 | `px-4 py-6`，≥640px 时 `px-8 py-9` | `24px 20px`（写死） | 随断点自适应 |
| H1 标题 | 28px / 600 / `line-height: 42px` | **20px / 700 / 30px** | 28px / 600 / 42px |
| 卡片圆角 | `16px`（`rounded-2xl`） | **12px** | 16px |

实测数据来源：浏览器读取官方页面 computed style，
而非截图比对 —— 这样能拿到精确值，也避免了对图片内容的依赖。

窄屏（≤560px）下标题区改为纵向堆叠，避免标题与右侧状态徽章抢同一行，
同时标题降到 24px / 34px，适配小屏。

## 2. 侧边栏收纳后「每日任务」悬停无提示

### 问题

侧边栏收拢后只剩图标，官方导航项悬停时会弹出名称气泡，
但「每日任务」悬停**没有任何提示**。

### 根因

收拢态气泡靠 CSS 取值：

```css
aside.wb-collapsed nav a:hover::after {
  content: attr(data-wb-label);
}
```

官方导航项由 `wrapNavLabels()` 统一设置 `data-wb-label`；
而**每日任务是后来注入的导航项，没有设置该属性**，
所以 `attr(data-wb-label)` 取到空值，气泡不显示。

### 修复

注入导航项时补上 `data-wb-label="每日任务"`。

## 3. 浮窗四个数值颜色各不相同

此前「今日消耗」与「账号池」**同为橙色**，无法分辨。

现改为四种**互不相同的亮色**：

| 行 | 颜色 |
| :--- | :--- |
| 总积分 | 蓝 `#2563eb` |
| 今日消耗 | 橙 `#ea580c` |
| 今日积分 | 绿 `#16a34a` |
| 账号池 | 紫 `#9333ea` |

账号池原先按「是否全部启用」在绿 / 橙之间切换 —— 会与「今日积分」「今日消耗」
撞色，现统一为紫色。

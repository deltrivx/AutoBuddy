# AutoBuddy v0.9.33

> 移除密钥列表头部的全局「累计调用」汇总，彻底修正调用量的归属。

## 起因

v0.9.32 发布后，用户追问：

> 仔细思考我说的和你做的，符合预期吗

逐条复盘后确认：**只做对了一半**。

## 自查发现

v0.9.32 给每个密钥行加了「调用 N 次」徽章（这一半是对的），
但**漏掉了密钥列表头部原本就存在的全局「累计调用 N 次」汇总**：

```js
"共 N 个，启用 N 个 · 累计调用 N 次 · 最近使用 ..."
```

这恰恰还是「主次关系混乱」本身 —— 调用量明明是每个密钥**各自**的属性，
标题上却仍摆着一个**全局**汇总，而且它比行内徽章更醒目（在主位）。

### 更该说明的一点

v0.9.32 的注释里写着：

> 它必须挂在密钥行内 —— 摆在外面会让人误以为是整个网关的调用量

而我自己摆在外面的那句**并没有删掉**。CHANGELOG 里
「每行有，徽章明确归属该密钥」的表述也掩盖了头部汇总仍在的事实。

按用户要求进行完整实现并交付前，应该逐条核对原话，而不是只报改了的部分。

## 修正

头部汇总已移除。现在只保留数量概览，并明确指引到各行：

```
改前：共 N 个，启用 N 个 · 累计调用 N 次 · 最近使用 ...
改后：共 N 个，启用 N 个。每个密钥各自的调用次数与来源白名单
      见下方各行 —— 它们是各自的，不是全局汇总。
```

## 至此两项都真正归位

| 项目 | v0.9.32 | v0.9.33 |
| :--- | :--- | :--- |
| 白名单 | 每行一份 + 全局兜底移到列表后 | 同（已完成） |
| 调用量 | 每行有徽章，但**头部全局汇总仍在** | **头部汇总已移除** |

现在「调用量」与「白名单」都只归属到每个单独的 API 密钥。

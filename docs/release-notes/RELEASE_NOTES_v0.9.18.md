# AutoBuddy v0.9.18

> 每日任务页：积分四项独立成框、最近记录独立、积分自动更新、清理多余显示。

## 1. 积分四项数据单独成为二级框（取消「框中框」）

原结构是「外层卡片 → 内层再套一个卡片」，与积分统计页不一致。

```
改前：wb-api-card  →  wb-dl-credit-card（嵌套）
改后：wb-dl-credit-card（独立，直接作为二级框）
```

同时取消了：

- 二级标题「积分统计」
- 说明文案「按每日任务历史记录累加（签到积分 + 任务积分）…」
- 右上角「刷新」按钮（刷新改由自动更新完成）

## 2. 最近记录单独出来

原先「最近 N 天明细」表格被塞在积分四项框**内部**。现拆为独立的
「最近记录」卡片，自带标题与说明：

```
积分四项框     ← 只有四项数据
最近记录卡片   ← 独立的明细表格
```

## 3. 积分自动更新

取消手动「刷新」按钮后，积分必须自己动 —— 否则数据会一直停在
进入页面那一刻。现在的行为：

| 场景 | 行为 |
| :--- | :--- |
| 停留本页且可见 | 每 **20 秒** 重拉 `credit-summary` 并重渲染 |
| 后台标签页（`document.hidden`） | 不请求，避免白烧流量 |
| hash 离开本页 | 不请求 |
| 切回页面（`visibilitychange`） | 立刻补拉一次，不等下一个周期 |

定时器**幂等只挂一次**，不会因重复加载数据而叠加多个定时器。

## 4. 取消多余的「正在执行」文案

「正在执行」这块平时是个空壳 —— 它只在任务真正运行时才由
`wbRenderDailyProgress` 填充内容。原先固定的标题文案属于多余显示，已移除。

> 注意：**卡片本体保留**，任务运行时仍正常显示进度条与阶段明细。

## 5. 移除右上角「待机 / 执行中」标志

该标记意义重复（下方调度配置区已有更完整的状态显示），
且在移动端会造成标题区布局混乱，已移除。
